# Toprak Karademir — Aerospace Engineering & Design Portfolio

Personal engineering and design portfolio website of **Toprak Karademir** (Aerospace Engineering student at Middle East Technical University / METU).

Built with React 18, Vite, Tailwind CSS v4, and Framer Motion. Modernized and refactored from Jeet's ([MAGGIx1404](https://github.com/MAGGIx1404/webgl-portfolio)) original WebGL template into a pure React architecture.

---

## 🛠️ Tech Stack

- **Framework**: React 18 / Vite 8
- **Styling**: Tailwind CSS v4 + Custom HSL Design Tokens
- **Animations & Motion**: Framer Motion 12
- **Routing**: React Router v7
- **Typography**: Roslindale Display Condensed, Ayer Medium, Neue Montreal
- **Deployment**: Vercel

---

## 🚀 Features

- **Interactive Landing Splash**: Dynamic slide-up headline animations with custom width-fill effects.
- **Parallax Hero & Smooth Motion**: Custom scroll physics, vertical parallax header movement, and dynamic skill word marquees.
- **Custom Hardware-Accelerated Cursor**: Interactive cursor ring with smooth 60fps tracking and hover state morphing.
- **Project Narratives**: Dedicated project detail pages for METU Rover Team, Industrial Solutions (Ostim Industrial Zone), Aerial Quadcopter Systems, Marine ROV Platforms, and Embedded Control Systems.
- **Responsive Architecture**: Fully optimized across desktop, tablet, and mobile displays.

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Suppanya/portfolio-site.git
   cd portfolio-site
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
